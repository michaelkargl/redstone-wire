## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Add getTicker() override to RedstoneInputBlock that returns RedstoneChainEntity::tick for periodic self-correction.

Without the ticker, RedstoneInputBlock relies solely on neighborChanged() for signal detection, which works in the happy path. The ticker acts as a safety net that periodically calls updateSignalInNetwork() to catch missed signals from:
- Block updates during world/chunk loading
- Piston moves or other edge cases where neighborChanged() notifications are unreliable
- Any timing-dependent update ordering issues

Only Input blocks should tick — Output and Connector blocks benefit automatically because updateSignalInNetwork() propagates to the whole network via applySignalToNetwork().
<!-- SECTION:DESCRIPTION:END -->
